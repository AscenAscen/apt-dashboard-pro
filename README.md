# 아파트 실거래가 대시보드

국토교통부 실거래가(매매·전세)를 GitHub가 **자동으로 모으고**, 검정 화면의 대시보드로 보여 줍니다.
내 컴퓨터를 켜 둘 필요가 없고, 비용도 들지 않습니다.

- 실거래 조회: 시/도 → 시/군/구 → 동 → 단지, 최대 20년, 전고점·전저점(2020년~), 전고대비 하락률, 전저대비 상승률, 엑셀, 지도
- 시세트래킹: 단지를 담아 두고 기준월 시세를 지정 양식 엑셀로 내려받기
- 시세그룹핑: 가로 생활권 × 세로 가격대 표 작성, 엑셀

---

## 처음 설치 (한 번만, 약 30분)

### 1단계. 국토부 API 인증키 받기
1. [공공데이터포털](https://www.data.go.kr) 회원가입 후 로그인
2. 검색창에 아래 두 가지를 각각 검색 → **오픈 API** 탭 → **활용신청** (활용목적은 "개인 연구" 등 자유롭게)
   - `국토교통부_아파트 매매 실거래가 상세 자료`
   - `국토교통부_아파트 전월세 실거래가 자료`
3. **마이페이지 → 데이터 활용 → Open API → 활용신청 현황**에서 신청한 항목을 누르면 **일반 인증키**가 보입니다.
   Encoding / Decoding 중 아무거나 하나를 복사해 메모장에 붙여 두세요. (두 API의 키는 같습니다)
4. 같은 화면의 **일일 트래픽** 숫자를 확인해 두세요. (보통 10,000. 1,000이면 아래 "호출 한도 조정" 참고)

> 키 발급 직후에는 1~2시간 동안 "등록되지 않은 키" 오류가 날 수 있습니다. 잠시 뒤 다시 실행하면 됩니다.

### 2단계. GitHub 저장소 만들기
1. [GitHub](https://github.com) 가입 후 로그인
2. 오른쪽 위 **+ → New repository**
   - Repository name: `apt-dashboard` (원하는 이름)
   - **Public** 선택 → **Create repository**

### 3단계. 파일 올리기
1. 받은 `apt-dashboard.zip` 압축을 풉니다.
2. 저장소 화면에서 **uploading an existing file** (또는 Add file → Upload files) 클릭
3. 압축을 푼 폴더 **안의 내용물 전부**를 끌어다 놓습니다.
   (`.github`, `config`, `css`, `data`, `js`, `lib`, `scripts`, `tests`, `index.html`, `README.md` …)
   - `.github` 폴더가 꼭 포함되어야 자동 수집이 됩니다. 맥에서는 Finder에서 `Cmd + Shift + .` 을 눌러야 보입니다.
4. 아래 **Commit changes** 클릭

### 4단계. 인증키 등록 (키는 남에게 보이지 않습니다)
1. 저장소 **Settings → Secrets and variables → Actions**
2. **New repository secret**
   - Name: `MOLIT_API_KEY`
   - Secret: 1단계에서 복사한 인증키
3. **Add secret**

### 5단계. 사이트 켜기
1. 저장소 **Settings → Pages**
2. **Source** 를 **GitHub Actions** 로 선택 (저장 버튼 없이 바로 적용)

### 6단계. 첫 수집 실행
1. 저장소 **Actions** 탭 (처음이면 초록색 "I understand…" 버튼을 눌러 사용 허용)
2. 왼쪽 **실거래가 자동 수집 · 사이트 배포** → 오른쪽 **Run workflow → Run workflow**
3. 초록 체크(✓)가 뜨면 성공. 빨간 ✗ 면 눌러서 "인증키 확인" 단계의 메시지를 확인하세요.

### 7단계. 접속
`https://내아이디.github.io/apt-dashboard/` (Settings → Pages 에 주소가 표시됩니다)

## 자동 수집은 이렇게 돕니다

| 항목 | 내용 |
|---|---|
| 실행 시각 | 2시간마다 (하루 호출 수는 수집기가 API별 9,500회 안에서 관리) |
| 최근 달 갱신 | 주요지역(서울·경기·광역시·세종·50만 이상 도시)은 **매일** 이번 달·지난달, 그 외 지역은 **매주 월요일**, 2~3달 전은 매월 1일·15일 |
| 과거 자료 | 최근 → 과거 순서로 조금씩 채움. ① 주요지역 2020년~ ② 그 외 2020년~ ③ 주요지역 2006년~ ④ 그 외 2006년~ |
| 소요 | 일일 한도 10,000 기준 **주요지역 2020년 이후는 2~3일**, 전국 20년 전체는 **약 1~2주** |
| 화면 표시 | 오른쪽 위에 "데이터 기준 시각 · 수집률"이 나옵니다 |

국토부 API가 불안정할 때를 대비한 장치
- 1회 실행당 호출 수 제한(기본 4,000회/API), 호출 사이 0.3초 간격
- 실패 시 3회 재시도, 연속 8회 실패하면 그날은 중단하고 다음 실행에서 **이어받기**
- 일일 한도 초과 응답을 받으면 즉시 멈춤
- 응답이 비정상적으로 적으면 기존 데이터를 **덮어쓰지 않음**

**호출 한도 조정** — 일일 트래픽이 1,000인 계정이면: Settings → Secrets and variables → Actions → **Variables** 탭 → New repository variable → Name `MAX_CALLS_PER_API`, Value `450`. (수집 기간은 그만큼 길어집니다)

## 화면 사용법

**최근 거래 (첫 화면)** — 지역별 최근 1개월 매매·전세 건수, 직전 1개월 대비 증감, 평균 매매가, 최고가 거래. 서울 → 수도권(경기·인천) → 광역시 순서로 고정되어 있고, 지역을 누르면 실거래 조회로 넘어갑니다. 자동 수집이 끝날 때마다 새로 만들어집니다.

**실거래 조회** — 지역·기간·매매/전세를 고르고 [조회]. 목록에서 단지를 누르면 그래프와 거래내역이 열립니다. "단지" 칸에서 단지를 고르고 **[단지 그래프 조회]** 를 누르면 그 단지 그래프가 바로 열리고, 누를 때마다 최신 자료를 다시 받습니다. 그래프 위에서 평형, 기간(빠른 선택 또는 시작 월~끝 월 직접 지정), 점/선 표시를 바꿀 수 있습니다. 시세트래킹에 적어 둔 가격은 그래프에 마름모로 함께 표시됩니다. 상세 화면 맨 아래에서 평형·기간(최대 20년)을 골라 엑셀이나 CSV로 내려받습니다.

**입지 분석** — 단지를 고르면 반경 500m·1km 안의 지하철·학교·마트·병원·학원 수, 강남·여의도·광화문까지 직선거리, 지도와 로드뷰 나란히 보기, 가장 가까운 초등학교 연결선을 보여 줍니다. (카카오 키 필요)

**단지 비교** — 단지 A·B를 골라 한 그래프에 겹쳐 봅니다(월평균 선, 거래 건수 막대, 전고·전저 표시). 기간은 1년·3년·5년·전체 버튼이나 시작일·종료일 달력으로 정합니다. 아래로 호가 흐름과 투자금, 수익률 표, 지도와 직선거리, 입지 비교(교통·학군·환경·호재), 기본 비교표, 월별 실거래 비교표가 이어집니다. **표시 항목 고르기**에서 항목을 켜고 끌 수 있고 직거래 숨김·1~3층 제외도 여기서 고릅니다. 입지 비교의 "직접 입력" 줄(대중교통 시간, 배정 학교, 경사, 호재 등)은 적어 두면 저장되고 입지 분석 탭과 함께 쓰입니다.

**전수조사** — 지역을 고르고 **이 지역 모든 단지 불러오기**를 누르면 모든 단지·평형이 시세트래킹과 같은 양식의 표로 나옵니다. **달 추가**로 기록할 달을 만들고 매매·전세 호가(억 단위)와 매물 수, 세대수를 적습니다. 가격대·동·평형·준공 연도·세대수로 좁히고, 매매 호가·세대수·평수 등으로 정렬한 뒤, 체크해서 **시세트래킹에 담기**를 누릅니다. 여기서 적은 값은 시세트래킹과 같은 곳에 저장됩니다. 호가가 없는 단지는 최근 실거래가 기준으로 가격대에 잡히며 "실" 표시가 붙습니다.

**시세트래킹** — 담아 둔 단지의 가격을 달마다 직접 기록합니다.
- **[시세 추가]** 를 누르면 그 달의 칸 묶음(매매/매매 개수/전월 대비/전세/전세 개수/전월 대비/매-전/전월 대비/전세가율/전월 대비)이 맨 앞에 생기고, 예전 기록은 오른쪽으로 밀려 계속 남습니다.
- 매매·전세는 **억 단위**로 적습니다. 예: 14억 3천만 원 → `14.3`. 엑셀에는 만원 단위로 나갑니다.
- 전고점·전저점은 2020년 이후 실거래(직거래 제외)로 자동 기입되고, 칸을 눌러 고칠 수 있습니다(지우면 자동값). 하락률·상승률은 가장 최근에 적은 매매가 기준으로 즉시 계산됩니다.
- **[실거래 불러오기]** 는 가장 최근 매매·전세 실거래가와 거래일을 창으로 보여 줍니다.
- **폴더**로 단지를 나눠 담습니다. 조회 탭에서 담을 때는 지금 보고 있는 폴더로 들어갑니다.
- 연식·연차는 자동이고, **세대수·구조·방·화는 직접 입력**합니다(실거래 자료에 없음).
- **[실거래 내역 다운로드]** 는 담아 둔 단지의 전체 실거래(최대 20년)를 엑셀/CSV로 받습니다.
- 목록은 사용 중인 브라우저에 저장됩니다. **[목록 백업]** 으로 파일로 보관하세요.

**지역 동향** — 시/군/구와 평형대를 고르면 2020년 이후 월별 거래량, 최근 신고가 거래, 전고점보다 10% 이상 낮게 거래된 매매를 찾아 줍니다.

**시세그룹핑** — 생활권(가로)과 가격대(세로)를 만들고 칸에 단지를 적습니다. 단지를 검색해 누르면 최근 실거래가에 맞는 칸에 들어가고, 트래킹에서 "생활권"을 적어 둔 단지는 [자동 배치]로 한 번에 들어갑니다.

## 카카오맵 연결 (지도·입지 분석·단지 비교 지도)

1. [카카오디벨로퍼스](https://developers.kakao.com)에서 앱을 **하나** 만들고 카카오맵 사용을 켭니다.
2. JavaScript 키의 **JavaScript SDK 도메인**에 `https://내아이디.github.io` 를 등록합니다.
3. GitHub에서 `js/config.js` 를 열어 연필(✏)을 누르고 `KAKAO_JS_KEY: '',` 의 따옴표 안에 **JavaScript 키**를 붙여 넣은 뒤 Commit 합니다.
   (REST API 키·어드민 키는 넣지 마세요. 저장소가 공개라 누구나 볼 수 있습니다.)

켜지는 기능: 위치 창이 카카오맵으로 바뀜 / **단지 비교** 탭의 지도(빨간 점, 단지 간·강남역까지 점선과 거리) / **입지 분석** 탭 전체.

대중교통 소요 시간은 자동으로 계산하지 않습니다. 단지 비교·입지 분석의 입지 표에 직접 적는 칸이 있고, 카카오맵 길찾기 버튼으로 확인할 수 있습니다.

## 휴대폰에 앱처럼 설치 (안드로이드)

1. 휴대폰 **크롬**으로 사이트 주소에 접속합니다.
2. 오른쪽 위 **⋮ → 홈 화면에 추가**(또는 **앱 설치**)를 누릅니다.
3. 홈 화면의 아이콘으로 열면 주소창 없이 전체 화면으로 뜹니다.

트래킹 목록은 기기마다 따로 저장됩니다. PC의 목록을 휴대폰에서 쓰려면 **목록 백업** 파일을 휴대폰으로 보내 **백업 불러오기** 하세요.
설치 파일(.apk)이 꼭 필요하면 이 사이트 주소를 [PWABuilder](https://www.pwabuilder.com)에 넣어 안드로이드 패키지를 만들 수 있습니다(`manifest.json`, `sw.js`, `icons` 가 그 용도입니다).

## 접속 비밀번호 걸기 (원할 때만)

1. 사이트 주소 뒤에 `#pw` 를 붙여 접속합니다. 예: `https://내아이디.github.io/저장소이름/#pw`
2. 쓰고 싶은 비밀번호를 입력하고 **만들기**를 누르면 `PASSWORD_HASH: '…',` 한 줄이 나옵니다. 복사합니다.
3. GitHub에서 `js/config.js` 를 열어 연필(✏)을 누르고, `PASSWORD_HASH: '',` 줄을 복사한 줄로 바꾼 뒤 Commit 합니다.
4. 1~2분 뒤부터 접속할 때 비밀번호를 묻습니다. 한 번 맞게 입력한 브라우저는 다시 묻지 않습니다.
5. 끄려면 다시 `PASSWORD_HASH: '',` 로 되돌립니다.

> 이 비밀번호는 **화면을 가리는 잠금**입니다. 저장소가 Public 이라 수집된 실거래 데이터 파일과 코드는 GitHub 에서 누구나 볼 수 있습니다(공개 자료라 문제는 없습니다). 시세트래킹·그룹핑 목록은 원래 내 브라우저에만 저장되므로 남에게 보이지 않습니다.

## 꼭 알아 둘 점

- **"실시간"의 의미**: 실거래는 계약 후 30일 안에 신고되고, 국토부 공개 자료는 하루 단위로 갱신됩니다. 이 대시보드는 하루 2회 반영합니다.
- **지역코드**: `config/regions.csv` 는 2024년 8월 기준 코드표입니다. 그 이후 바뀐 곳(2026년 인천 제물포구·영종구·검단구 신설, 화성시 4개 구 설치, 광주·전남 통합 등)은 새 코드로 자료가 내려올 수 있습니다. 1년치 이상 받았는데 단지가 0개인 지역은 화면 오른쪽 위에 "⚠ 자료 없는 지역"으로 표시되니, 그때 해당 줄의 코드를 새 코드로 바꾸면 됩니다.
- **해제(취소)된 거래와 월세는 제외**합니다. 직거래는 포함하되 "직거래 제외"를 체크하면 전고점·전저점 계산에서 빠집니다(직거래 구분은 2021년 말 이후 자료부터 제공).
- 평형은 전용면적으로 추정한 값이라 실제 공급평형과 1~2평 다를 수 있습니다. 트래킹 표에서 직접 고칠 수 있습니다.
- 지도는 주소(지번)로 구글 지도를 띄우고, 네이버지도·카카오맵·네이버부동산 버튼으로 바로 넘어갈 수 있습니다.
- 자료 출처: 국토교통부 실거래가 공개시스템 (공공데이터포털)
