# 아파트 실거래가 대시보드

국토교통부 실거래가(매매·전세)를 GitHub가 **자동으로 모으고**, 검정 화면의 대시보드로 보여 줍니다.
내 컴퓨터를 켜 둘 필요가 없고, 비용도 들지 않습니다.

- 실거래 조회: 시/도 → 시/군/구 → 동 → 단지, 최대 20년, 전고점(2020년~ 최고가)·전저점(전고점 이후 최저가 = 하락장 바닥), 전고대비 하락률, 전저대비 상승률, 엑셀, 지도
- 시세트래킹: 단지를 담아 두고 기준월 시세를 지정 양식 엑셀로 내려받기
- 시세그룹핑: 가로 생활권 × 세로 가격대 표 작성, 엑셀

## 처음 설치 (한 번만, 약 30분)

### 1단계. 국토부 API 인증키 받기
1. [공공데이터포털](https://www.data.go.kr) 회원가입 후 로그인
2. 검색창에 아래 두 가지를 각각 검색 → **오픈 API** 탭 → **활용신청** (활용목적은 "개인 연구" 등 자유롭게)
   - `국토교통부_아파트 매매 실거래가 상세 자료`
   - `국토교통부_아파트 전월세 실거래가 자료`
3. **마이페이지 → 데이터 활용 → Open API → 활용신청 현황**에서 신청한 항목을 누르면 **일반 인증키**가 보입니다.
   Encoding / Decoding 중 아무거나 하나를 복사해 메모장에 붙여 두세요. (두 API의 키는 같습니다)
4. 같은 화면의 **일일 트래픽** 숫자를 확인해 두세요. (보통 10,000. 1,000이면 아래 "호출 한도 조정" 참고)

> 키 발급 직후에는 1~2시간 동안 "등록되지 않은 키" 오류가 날 수 있습니다. 잠시 뒤 다시 실행하면 됩니다.

### 2단계. GitHub 저장소 만들기
1. [GitHub](https://github.com) 가입 후 로그인
2. 오른쪽 위 **+ → New repository**
   - Repository name: `apt-dashboard` (원하는 이름)
   - **Public** 선택 → **Create repository**

### 3단계. 파일 올리기
1. 받은 `apt-dashboard.zip` 압축을 풉니다.
2. 저장소 화면에서 **uploading an existing file** (또는 Add file → Upload files) 클릭
3. 압축을 푼 폴더 **안의 내용물 전부**를 끌어다 놓습니다.
   (`.github`, `config`, `css`, `data`, `js`, `lib`, `scripts`, `tests`, `index.html`, `README.md` …)
   - `.github` 폴더가 꼭 포함되어야 자동 수집이 됩니다. 맥에서는 Finder에서 `Cmd + Shift + .` 을 눌러야 보입니다.
4. 아래 **Commit changes** 클릭

### 4단계. 인증키 등록 (키는 남에게 보이지 않습니다)
1. 저장소 **Settings → Secrets and variables → Actions**
2. **New repository secret**
   - Name: `MOLIT_API_KEY`
   - Secret: 1단계에서 복사한 인증키
3. **Add secret**

### 5단계. 사이트 켜기
1. 저장소 **Settings → Pages**
2. **Source** 를 **GitHub Actions** 로 선택 (저장 버튼 없이 바로 적용)

### 6단계. 첫 수집 실행
1. 저장소 **Actions** 탭 (처음이면 초록색 "I understand…" 버튼을 눌러 사용 허용)
2. 왼쪽 **실거래가 자동 수집 · 사이트 배포** → 오른쪽 **Run workflow → Run workflow**
3. 초록 체크(✓)가 뜨면 성공. 빨간 ✗ 면 눌러서 "인증키 확인" 단계의 메시지를 확인하세요.

### 7단계. 접속
`https://내아이디.github.io/apt-dashboard/` (Settings → Pages 에 주소가 표시됩니다)

## 자동 수집은 이렇게 돕니다

| 항목 | 내용 |
|---|---|
| 실행 시각 | 2시간마다 (하루 호출 수는 수집기가 API별 9,500회 안에서 관리) |
| 최근 달 갱신 | 주요지역(서울·경기·광역시·세종·50만 이상 도시)은 **매일** 이번 달·지난달, 그 외 지역은 **매주 월요일**, 2~3달 전은 매월 1일·15일 |
| 과거 자료 | 최근 → 과거 순서로 조금씩 채움. ① 주요지역 2020년~ ② 그 외 2020년~ ③ 주요지역 2006년~ ④ 그 외 2006년~ |
| 소요 | 일일 한도 10,000 기준 **주요지역 2020년 이후는 2~3일**, 전국 20년 전체는 **약 1~2주** |
| 화면 표시 | 오른쪽 위에 "데이터 기준 시각 · 수집률"이 나옵니다 |

국토부 API가 불안정할 때를 대비한 장치
- 1회 실행당 호출 수 제한(기본 4,000회/API), 호출 사이 0.3초 간격
- 실패 시 3회 재시도, 연속 8회 실패하면 그날은 중단하고 다음 실행에서 **이어받기**
- 일일 한도 초과 응답을 받으면 즉시 멈춤
- 응답이 비정상적으로 적으면 기존 데이터를 **덮어쓰지 않음**

**호출 한도 조정** — 일일 트래픽이 1,000인 계정이면: Settings → Secrets and variables → Actions → **Variables** 탭 → New repository variable → Name `MAX_CALLS_PER_API`, Value `450`. (수집 기간은 그만큼 길어집니다)

## 화면 사용법

**최근 거래 (첫 화면)** — 지역별 최근 1개월 매매·전세 건수, 직전 1개월 대비 증감, 평균 매매가, 최고가 거래. 서울 → 수도권(경기·인천) → 광역시 순서로 고정되어 있고, 지역을 누르면 실거래 조회로 넘어갑니다. 자동 수집이 끝날 때마다 새로 만들어집니다.

**실거래 조회** — 지역·기간·매매/전세를 고르고 [조회]. 목록에서 단지를 누르면 그래프와 거래내역이 열립니다. "단지" 칸에서 단지를 고르고 **[단지 그래프 조회]** 를 누르면 그 단지 그래프가 바로 열리고, 누를 때마다 최신 자료를 다시 받습니다. 그래프 위에서 평형, 기간(빠른 선택 또는 시작 월~끝 월 직접 지정), 점/선 표시를 바꿀 수 있습니다. 시세트래킹에 적어 둔 가격은 그래프에 마름모로 함께 표시됩니다. 상세 화면 맨 아래에서 평형·기간(최대 20년)을 골라 엑셀이나 CSV로 내려받습니다.

**입지 분석** — 단지를 고르면 반경 500m·1km 안의 지하철·학교·마트·병원·학원 수, 강남·여의도·광화문까지 직선거리, 지도와 로드뷰 나란히 보기, 가장 가까운 초등학교 연결선을 보여 줍니다. (카카오 키 필요)

**단지 비교** (입지 비교 표 추가 기능) — 자동으로 채워진 값(지하철·학교·마트·백화점·종합병원·스타벅스 거리 등) 옆 **✎** 를 누르면 직접 고칠 수 있고, 고친 값은 **📌 고정**되어 다시 불러와도 덮어쓰지 않습니다(📌 을 누르면 자동 값으로 복귀). 도보 시간은 직선거리 기준 추정(직선거리 × 1.3 ÷ 분당 67m)입니다. 항목 이름을 누르면 이름을 바꿀 수 있고(예: "강남역 대중교통" → "KTX역 소요 시간"), 중학교 학업성취도(%)는 입력 칸에 적고 옆 [아실]·[호갱노노] 버튼으로 확인합니다. 기본 비교표에는 **현재 가격(직접 입력)** 칸이 있어 적으면 전고점(2020년~) 대비 하락률이 바로 계산됩니다. 여기서 적은 입지 메모는 시세지도 카드와 임장 탭에도 그대로 보입니다.

**단지 비교** — 단지 A·B를 골라 한 그래프에 겹쳐 봅니다(월평균 선, 거래 건수 막대, 전고·전저 표시). 기간은 1년·3년·5년·전체 버튼이나 시작일·종료일 달력으로 정합니다. 아래로 호가 흐름과 투자금, 수익률 표, 지도와 직선거리, 입지 비교(교통·학군·환경·호재), 기본 비교표, 월별 실거래 비교표가 이어집니다. **표시 항목 고르기**에서 항목을 켜고 끌 수 있고 직거래 숨김·1~3층 제외도 여기서 고릅니다. 입지 비교의 "직접 입력" 줄(대중교통 시간, 배정 학교, 경사, 호재 등)은 적어 두면 저장되고 입지 분석 탭과 함께 쓰입니다.

**실거래 조회 — 선택 단지 브리핑** — 목록에서 체크한 단지(최대 12개)가 목록 아래 카드로 요약됩니다(최근 매매·전고점·전고 대비·전저 대비·전세·전세가율·내 호가).

**전수조사** — 두 부분으로 되어 있습니다.
- **내 조사 기록**: 지금까지 호가를 적은 지역을 시/군/구 → 동 순서로, 달별로 보여 줍니다(입력한 단지 수, 평균 매매 호가, 마지막 입력일). 조사 이름·메모를 적고 완료 표시를 할 수 있습니다. [열기]는 그 조사 화면으로, [비교]는 바로 앞 조사와의 비교로 갑니다. **지난 조사와 비교**는 같은 구(또는 동)의 두 달을 골라 단지별 매매·전세·매물 수·투자금 변동과 요약을 보여 줍니다.
- **조사 화면**: 지역을 고르고 **이 지역 모든 단지 불러오기** → **달 추가**로 기록할 달을 만들고 호가를 적습니다. 가격대·동·평형·준공 연도·세대수·생활권·상태로 좁히고 정렬한 뒤 **시세트래킹에 담기**. ☆ 로 후보 표시, **엑셀 붙여넣기**로 한꺼번에 입력, **지난 기록과 같음**은 체크한 단지에만 적용됩니다.

**시세트래킹** — 담아 둔 단지의 가격을 달마다 직접 기록합니다.
- 맨 위 **폴더 버튼**으로 폴더를 오갑니다(단지 수와 평균 전월 대비 표시). 한 단지를 여러 폴더에 담을 수 있습니다.
- **[시세 추가]** 로 달의 칸 묶음을 만들고 매매·전세(억 단위)와 매물 수를 적습니다. 예전 기록은 오른쪽으로 쌓입니다. 처음 단지를 담으면 이번 달 칸이 자동으로 생깁니다.
- **상태**(관심/임장 예정/임장 완료/매수 후보/제외)와 **메모**를 단지마다 남기고, 상태·보기·정렬 상자로 걸러 봅니다.
- 오른쪽 위에 **이번 달 입력 진행 상황**이 나옵니다. "최신 달 아직 안 적은 단지"만 볼 수 있고, **지난 기록과 같음**으로 변동 없는 단지를 한 번에 채웁니다.
- **호가-실거래** 칸은 적은 매매 호가와 최근 실거래가의 차이입니다.
- 담아 둔 단지에 **새 실거래**가 등록되면 표 위에 알림이 뜹니다.
- **단지 정보 펼치기**로 생활권·세대수·구조·방·화·링크 칸을 여닫고, 단지명 칸은 옆으로 밀어도 고정됩니다.
- **카드로 입력**: 단지 하나를 카드 한 장으로 보여 줍니다(휴대폰에서는 기본).
- **[실거래 불러오기]** 는 가장 최근 매매·전세 실거래가와 거래일을 창으로 보여 줍니다.
- 폴더 관리, 백업, 내려받기, 삭제는 **관리** 안에 있습니다.

**시세지도** — 시세트래킹에 담은 단지를 카카오맵에 올리고 라벨에 단지명과 가격(매매·전세·매-전·전세가율)을 보여 줍니다. 폴더별로 볼 수 있고, 내가 적은 호가가 먼저, 호가가 없는 단지만 최근 실거래(라벨에 `·실`, 주황색)로 대신합니다.
- 라벨이 겹치면 상하좌우로 자동으로 밀어 배치하고, 멀어진 라벨에는 가는 연결선이 생깁니다.
- **라벨 편집 모드**를 켜면 라벨을 마우스·손가락으로 끌어 옮길 수 있습니다(위치 저장). 라벨을 한 번 누르면 그 라벨만 크기·글자 크기를 따로 조정합니다. [위치 초기화]로 자동 배치로 되돌립니다.
- 위쪽 슬라이더로 전체 **라벨 크기(배율)** 와 **글자 크기(px)** 를 바꿉니다. 랜드마크 지도도 같은 도구를 씁니다.
- **📷 깔끔하게 캡처 모드**: 버튼·검색창·탭·확대 버튼을 숨기고 지도와 라벨만 남깁니다. 끝내려면 왼쪽 위 흐린 ✕ 또는 Esc. (실제 저장은 기기의 화면 캡처를 쓰세요.)

**지역 동향** — 시/군/구와 평형대를 고르면 2020년 이후 월별 거래량, 최근 신고가 거래, 전고점보다 10% 이상 낮게 거래된 매매를 찾아 줍니다.

**시세그룹핑** — 생활권(가로)과 가격대(세로)를 만들고 칸에 단지를 적습니다. 단지를 검색해 누르면 최근 실거래가에 맞는 칸에 들어가고, 트래킹에서 "생활권"을 적어 둔 단지는 [자동 배치]로 한 번에 들어갑니다.

## 가이드·설정 탭의 설정

- **탭 설정**: 체크를 끄면 그 탭이 메뉴에서 사라지고, ▲▼ 로 순서를 바꿉니다. (설정 탭은 항상 보입니다)
- **업무지구 설정**: 단지 비교·입지 분석의 "업무지구 직선거리" 기준점을 바꿉니다. 이름과 지도 검색어(예: `부산 서면역`)만 저장하고, 좌표는 열 때마다 카카오맵으로 다시 찾습니다. 비우면 강남·여의도·광화문입니다.
- **백업·옮기기**: 코드/파일 백업에 시세트래킹뿐 아니라 라벨 위치, 입지 메모(고친 값·항목 이름 포함), 탭 설정, 현재 가격 입력값이 함께 들어갑니다.

2. JavaScript 키의 **JavaScript SDK 도메인**에 `https://내아이디.github.io` 를 등록합니다.
3. GitHub에서 `js/config.js` 를 열어 연필(✏)을 누르고 `KAKAO_JS_KEY: '',` 의 따옴표 안에 **JavaScript 키**를 붙여 넣은 뒤 Commit 합니다.
   (REST API 키·어드민 키는 넣지 마세요. 저장소가 공개라 누구나 볼 수 있습니다.)

켜지는 기능: 위치 창이 카카오맵으로 바뀜 / **단지 비교** 탭의 지도(빨간 점, 단지 간·강남역까지 점선과 거리) / **입지 분석** 탭 전체.

대중교통 소요 시간은 자동으로 계산하지 않습니다. 단지 비교·입지 분석의 입지 표에 직접 적는 칸이 있고, 카카오맵 길찾기 버튼으로 확인할 수 있습니다.

## 내 기록은 어디에 있고, 누가 바꿀 수 있나

- 호가, 트래킹 목록, 폴더, 전수조사 기록, 메모는 **내 브라우저 안에만** 저장됩니다. 다른 사람이 같은 주소로 접속하면 빈 화면이 뜨고, 그 사람이 적은 것은 그 사람 브라우저에만 남습니다. 서로 보이지도 바뀌지도 않습니다.
- 실거래 데이터와 화면 파일은 GitHub 저장소에 있고 누구나 볼 수 있지만, 고칠 수 있는 사람은 저장소 주인뿐입니다.
- **기기 사이 옮기기**: 관리 → **코드로 내보내기**로 복사한 글자를 다른 기기의 **코드 가져오기**에 붙여 넣습니다. "합치기"를 고르면 양쪽 기록을 모두 살리고, 같은 칸이 겹치면 가져온 값을 씁니다.
- **백업**: 백업 파일 저장·불러오기도 같은 곳에 있습니다. 14일 넘게 백업하지 않으면 알림이 뜹니다. 브라우저 기록을 지우면 내 기록도 사라지니 가끔 받아 두세요.
- **잠금**: 오른쪽 위 **잠금**을 켜면 적어 둔 값을 고치거나 지울 수 없습니다. 남에게 화면을 보여 줄 때 쓰세요.
- 폴더, 달 기록, 단지 3개 이상을 지울 때는 "삭제"라고 직접 입력해야 진행됩니다.

## 접속 비밀번호 걸기 (원할 때만)

1. 사이트 주소 뒤에 `#pw` 를 붙여 접속합니다. 예: `https://내아이디.github.io/저장소이름/#pw`
2. 쓰고 싶은 비밀번호를 입력하고 **만들기**를 누르면 `PASSWORD_HASH: '…',` 한 줄이 나옵니다. 복사합니다.
3. GitHub에서 `js/config.js` 를 열어 연필(✏)을 누르고, `PASSWORD_HASH: '',` 줄을 복사한 줄로 바꾼 뒤 Commit 합니다.
4. 1~2분 뒤부터 접속할 때 비밀번호를 묻습니다. 한 번 맞게 입력한 브라우저는 다시 묻지 않습니다.
5. 끄려면 다시 `PASSWORD_HASH: '',` 로 되돌립니다.

> 이 비밀번호는 **화면을 가리는 잠금**입니다. 저장소가 Public 이라 수집된 실거래 데이터 파일과 코드는 GitHub 에서 누구나 볼 수 있습니다(공개 자료라 문제는 없습니다). 시세트래킹·그룹핑 목록은 원래 내 브라우저에만 저장되므로 남에게 보이지 않습니다.

## 꼭 알아 둘 점

- **"실시간"의 의미**: 실거래는 계약 후 30일 안에 신고되고, 국토부 공개 자료는 하루 단위로 갱신됩니다. 이 대시보드는 하루 2회 반영합니다.
- **지역코드**: `config/regions.csv` 는 2024년 8월 기준 코드표입니다. 그 이후 바뀐 곳(2026년 인천 제물포구·영종구·검단구 신설, 화성시 4개 구 설치, 광주·전남 통합 등)은 새 코드로 자료가 내려올 수 있습니다. 1년치 이상 받았는데 단지가 0개인 지역은 화면 오른쪽 위에 "⚠ 자료 없는 지역"으로 표시되니, 그때 해당 줄의 코드를 새 코드로 바꾸면 됩니다.
- **해제(취소)된 거래와 월세는 제외**합니다. 직거래는 포함하되 "직거래 제외"를 체크하면 전고점·전저점 계산에서 빠집니다(직거래 구분은 2021년 말 이후 자료부터 제공).
- 평형은 전용면적으로 추정한 값이라 실제 공급평형과 1~2평 다를 수 있습니다. 트래킹 표에서 직접 고칠 수 있습니다.
- 지도는 주소(지번)로 구글 지도를 띄우고, 네이버지도·카카오맵·네이버부동산 버튼으로 바로 넘어갈 수 있습니다.
- 자료 출처: 국토교통부 실거래가 공개시스템 (공공데이터포털)

  - 수도권 기준: 3대 업무지구 직선거리, 강남역 대중교통(추정), 초·중학교 도보 거리와 학업성취도, 백화점·마트·병원·스타벅스 주변 여부

  - 자동 값은 ✎ 로 고치면 📌 으로 고정되고, 📌 을 누르면 자동 값으로 돌아갑니다. 항목 이름 바꾸기, 항목 추가, 단지 빼기가 가능합니다.
  - 입지 값(apt.loc.v1)과 현재가(apt.cmpPrice.v1)는 단지 비교·입지 분석 탭과 같은 저장소를 씁니다.
  - 대중교통 시간은 직선거리로 계산한 **추정치**입니다. 실제 시간은 직접 적어 주세요.
  - 구/군 입주 물량·인구·순위는 자동으로 가져오는 자료가 없어서 직접 입력합니다.

부동산지인 입주물량 엑셀을 올리면 **공급 지도 · 요약 · 공급 그래프(적정 수요선) · 단지 목록 · 분양가 vs 주변 시세**를 보여 줍니다.

### 쓰는 법
1. 부동산지인 입주물량 화면에서 지역을 고르고 **엑셀 다운로드**
2. 대시보드 **[공급지도] 탭 → [📂 엑셀 올리기]** 로 그 파일을 그대로 올리기
3. 지역마다 따로 올리면 합쳐집니다. 같은 지역을 다시 올리면 [바꾸기 / 합치기]를 고릅니다.
   입주시기가 바뀐 단지는 목록과 카드에 "변경 ←" 으로 표시됩니다.

- 자료는 **이 브라우저에만** 저장됩니다 (공개 저장소에 올리지 않음). 전체 백업·코드 내보내기에 함께 들어갑니다.
- 지도 위치는 카카오 주소 검색으로 그때그때 찾습니다 (카카오 정책상 좌표는 저장하지 않음).
  못 찾은 단지는 [📍]를 누르고 지도에서 찍으면 그 위치만 저장됩니다.
- 라벨 모양은 지도 오른쪽 위 **[🎨 라벨 꾸미기]** 에서 고릅니다 (추천 조합 4개, 스타일 5종, 내 스타일 3개 저장).
- 맨 아래 **분양가 vs 주변 시세**는 청약홈 자동 수집 자료(`data/supply.json`)로, 위에서 고른 시도·시군구를 그대로 따릅니다.

### 적정 수요선 (인구)
- `scripts/population.py` 가 행정안전부 주민등록 인구(시군구)를 **한 달에 한 번** 자동으로 받아 `data/population.json` 에 저장합니다.
- 공공데이터포털에서 **행정안전부_법정동별(행정동 통반단위) 주민등록 인구 및 세대현황** 활용신청이 되어 있어야 합니다.
  인증키는 실거래와 같은 `MOLIT_API_KEY` 를 그대로 씁니다. (다른 키를 쓰려면 Secrets 에 `POP_API_KEY` 추가)
- 결과·오류는 `data/population_status.json` 에서 확인할 수 있습니다. 바로 받아 보려면 Actions → **Run workflow**.

## 공급 탭 (청약홈 · 자동)

청약홈 분양 공고를 **매주 자동으로** 받아 입주 물량(적정 수요선) · 입주 단지 지도 · 입주 예정 표를 보여 줍니다.

- 수집: `scripts/supply.py` (`.github/workflows/supply.yml`, 매주 월요일). 키는 실거래와 같은 `MOLIT_API_KEY`
  (공공데이터포털 **청약홈 분양정보 조회 서비스**, **청약홈 청약접수 경쟁률 조회 서비스** 활용신청 필요)
- 결과·오류·받은 칸 이름: `data/supply_status.json`
- 세대수는 모집공고의 공급 세대(일반분양) 기준이라 재건축·재개발은 실제보다 적게 잡힐 수 있습니다. 정확한 입주 물량은 [공급지도] 탭.
- 주소 → 지역: 행정구역 개편(인천 서해·검단·영종·제물포구, 화성특례시 구, 전남광주통합특별시)과 시도 없는 주소·붙여 쓴 주소도 맞춥니다.
  세종은 실거래 지역 목록에 없어 지역 선택에 나오지 않습니다.

## 인구이동 탭 (통계청 KOSIS · 자동)

- **무엇을 보나**: 시군구별 전입·전출·순이동(들어온 사람 − 나간 사람), 인구 대비 순이동률, 시도 간 이동, 같은 기간 입주 물량
- **화면 순서**: ① 지역·기간(1개월 / 3개월 합계 / 12개월 합계, 기준 월) → ② 요약 4칸 → ③ 순이동 지도(원 크기 = 규모, 주황 = 유입, 파랑 = 유출) → ④ 월별 순이동 그래프 + 입주 물량 → ⑤ 시도 간 이동 → ⑥ 순위표(엑셀식 필터 ▾ · 엑셀 내보내기)
- 지도 원이나 표의 줄을 누르면 그 지역만 그래프로 봅니다.
- **자료**: `scripts/migration.py` 가 매주 화요일 새벽(04:40) KOSIS 국내인구이동통계를 확인해 `data/migration.json` 에 저장 (처음엔 3년 치, 이후 최근 몇 달만 다시 받음)
- **준비**: GitHub → Settings → Secrets and variables → Actions → `KOSIS_API_KEY` 등록 → Actions → "인구이동 수집 (KOSIS)" → Run workflow
- 수집 결과·오류는 `data/migration_status.json` 에 남습니다. 인증키는 코드나 자료 파일에 절대 저장하지 않습니다.
- 시군구끼리의 이동(어디서 어디로)은 공개 통계에 없어 시도 단위로만 보여 줍니다.

## 어디서든 단지 찾기 (Ctrl+K)

- 어느 탭에서든 **Ctrl+K** (맥 ⌘K) 또는 **/** 키, 또는 위쪽 **🔍 단지 찾기** 버튼
- 단지 이름 · 별칭 · 동네 · 구 이름으로 찾기 (띄어 쓰면 모두 포함: "대치 은마", "평촌 래미안")
- **Enter** = 단지 한 장 요약 · **Shift+Enter** = 실거래 조회 탭에서 열기 · 줄의 버튼: 요약 / 실거래 / 지도 / 네이버
- 지역 이름(예: 강남구)이나 탭 이름(예: 공급)을 치면 그 지역·탭으로 바로 이동
- 최근 고른 단지 8개를 기억 (이 기기에만)

## 단지 지도 (첫 화면)

- **목적**: 고른 지역에 어떤 아파트 단지가 있는지 지도 라벨로 한눈에
- **라벨**: 단지명 · 연식 · 세대수. 👑 동마다 대장(200세대↑, 최근 1년 ㎡당 평균가 1위) · 🆕 5년 이내 신축 · ⭐ 시세트래킹에 담은 단지
- **마우스를 올리면 창** (휴대폰은 누르면 아래서 올라오는 판, 좌우로 밀면 평형 바꾸기)
  - A. 한 평형씩: ◀▶ 또는 ← → 로 평형 바꾸기 · 매매·전세 실거래 · 전고점·전저점(금액·날짜·지금 대비 %) · 전세가율·갭 · 내 호가
  - B. 평형별 표: 평형마다 최근 매매 · 전고점 · 전저점 (금액·날짜·% 칸 켜고 끄기)
  - 라벨을 누르면 📌 고정 → [단지 요약] [실거래] [☆ 시세트래킹] [네이버 부동산] [숨기기]
- **처음 열면 📍 내 위치 주변** (허용 안 하면 마지막에 본 지역). 지도를 옮기면 화면 가운데 시군구를 저절로 불러옴
- **조건**: 평형(소형·59·74·84·대형) · 세대수(300↑…, 직접) · 연식(5·10·20년↓, 직접) · ⭐ 내 단지만 · 거래 적은 단지(최근 5년 매매 5건 미만)는 기본 숨김
- **🎨 라벨 꾸미기**: 창 모양 A/B · 라벨 모양 5가지 · 색 5가지 · 크기·글자 · 글씨체 · 강조 표시 방식 · 지도 바탕 흐리게 · 프리셋(임장용·보고서용·간단히 + 내 프리셋 저장) · 📷 깔끔하게 캡처 모드
- **아래 단지 목록**: 지도에 나온 단지 표 (엑셀식 필터 ▾ · 엑셀), 줄을 누르면 지도에서 그 단지로
- 단지 위치는 카카오 주소 검색을 그때그때 씁니다 (카카오 약관상 좌표 저장 불가). 한 번 찾은 위치는 그 접속 동안만 기억합니다.
