# 아파트 실거래가 대시보드

국토교통부 실거래가(매매·전세)를 GitHub가 **자동으로 모으고**, 검정 화면의 대시보드로 보여 줍니다.
내 컴퓨터를 켜 둘 필요가 없고, 비용도 들지 않습니다.

- 실거래 조회: 시/도 → 시/군/구 → 동 → 단지, 최대 20년, 전고점·전저점(2020년~), 전고대비 하락률, 전저대비 상승률, 엑셀, 지도
- 시세트래킹: 단지를 담아 두고 기준월 시세를 지정 양식 엑셀로 내려받기
- 시세그룹핑: 가로 생활권 × 세로 가격대 표 작성, 엑셀

---

## 처음 설치 (한 번만, 약 30분)

### 1단계. 국토부 API 인증키 받기
1. [공공데이터포털](https://www.data.go.kr) 회원가입 후 로그인
2. 검색창에 아래 두 가지를 각각 검색 → **오픈 API** 탭 → **활용신청** (활용목적은 "개인 연구" 등 자유롭게)
   - `국토교통부_아파트 매매 실거래가 상세 자료`
   - `국토교통부_아파트 전월세 실거래가 자료`
3. **마이페이지 → 데이터 활용 → Open API → 활용신청 현황**에서 신청한 항목을 누르면 **일반 인증키**가 보입니다.
   Encoding / Decoding 중 아무거나 하나를 복사해 메모장에 붙여 두세요. (두 API의 키는 같습니다)
4. 같은 화면의 **일일 트래픽** 숫자를 확인해 두세요. (보통 10,000. 1,000이면 아래 "호출 한도 조정" 참고)

> 키 발급 직후에는 1~2시간 동안 "등록되지 않은 키" 오류가 날 수 있습니다. 잠시 뒤 다시 실행하면 됩니다.

### 2단계. GitHub 저장소 만들기
1. [GitHub](https://github.com) 가입 후 로그인
2. 오른쪽 위 **+ → New repository**
   - Repository name: `apt-dashboard` (원하는 이름)
   - **Public** 선택 → **Create repository**

### 3단계. 파일 올리기
1. 받은 `apt-dashboard.zip` 압축을 풉니다.
2. 저장소 화면에서 **uploading an existing file** (또는 Add file → Upload files) 클릭
3. 압축을 푼 폴더 **안의 내용물 전부**를 끌어다 놓습니다.
   (`.github`, `config`, `css`, `data`, `js`, `lib`, `scripts`, `tests`, `index.html`, `README.md` …)
   - `.github` 폴더가 꼭 포함되어야 자동 수집이 됩니다. 맥에서는 Finder에서 `Cmd + Shift + .` 을 눌러야 보입니다.
4. 아래 **Commit changes** 클릭

### 4단계. 인증키 등록 (키는 남에게 보이지 않습니다)
1. 저장소 **Settings → Secrets and variables → Actions**
2. **New repository secret**
   - Name: `MOLIT_API_KEY`
   - Secret: 1단계에서 복사한 인증키
3. **Add secret**

### 5단계. 사이트 켜기
1. 저장소 **Settings → Pages**
2. **Source** 를 **GitHub Actions** 로 선택 (저장 버튼 없이 바로 적용)

### 6단계. 첫 수집 실행
1. 저장소 **Actions** 탭 (처음이면 초록색 "I understand…" 버튼을 눌러 사용 허용)
2. 왼쪽 **실거래가 자동 수집 · 사이트 배포** → 오른쪽 **Run workflow → Run workflow**
3. 초록 체크(✓)가 뜨면 성공. 빨간 ✗ 면 눌러서 "인증키 확인" 단계의 메시지를 확인하세요.

### 7단계. 접속
`https://내아이디.github.io/apt-dashboard/` (Settings → Pages 에 주소가 표시됩니다)

## 자동 수집은 이렇게 돕니다

| 항목 | 내용 |
|---|---|
| 실행 시각 | 매일 새벽 4시경, 오후 1시경 (하루 2회) |
| 최근 달 갱신 | 주요지역(서울·경기·광역시·세종·50만 이상 도시)은 **매일** 이번 달·지난달, 그 외 지역은 **매주 월요일**, 2~3달 전은 매월 1일·15일 |
| 과거 자료 | 최근 → 과거 순서로 조금씩 채움. ① 주요지역 2020년~ ② 그 외 2020년~ ③ 주요지역 2006년~ ④ 그 외 2006년~ |
| 소요 | 일일 한도 10,000 기준 **주요지역 2020년 이후는 2~3일**, 전국 20년 전체는 **약 1~2주** |
| 화면 표시 | 오른쪽 위에 "데이터 기준 시각 · 수집률"이 나옵니다 |

국토부 API가 불안정할 때를 대비한 장치
- 1회 실행당 호출 수 제한(기본 4,000회/API), 호출 사이 0.3초 간격
- 실패 시 3회 재시도, 연속 8회 실패하면 그날은 중단하고 다음 실행에서 **이어받기**
- 일일 한도 초과 응답을 받으면 즉시 멈춤
- 응답이 비정상적으로 적으면 기존 데이터를 **덮어쓰지 않음**

**호출 한도 조정** — 일일 트래픽이 1,000인 계정이면: Settings → Secrets and variables → Actions → **Variables** 탭 → New repository variable → Name `MAX_CALLS_PER_API`, Value `450`. (수집 기간은 그만큼 길어집니다)

## 화면 사용법

**실거래 조회** — 지역·기간·매매/전세를 고르고 [조회]. 목록에서 단지를 누르면 그래프와 거래내역이 열립니다. 체크한 단지만 엑셀로 받거나 트래킹에 담을 수 있습니다. 시/군/구 이름 뒤의 `·` 는 주 1회 갱신 지역입니다.

**시세트래킹** — 담아 둔 단지의 기준월 시세를 계산합니다. 엑셀 양식:
`가격대/시/구/동/단지명/연식/연차/세대수/평형/구조(계,복)/방/화/링크/매매/매매개수/전월대비 매매/전세/전세개수/전월대비전세/매-전/전월대비 매-전/전세가율/전월대비 전세가율`
- 매매·전세 = 기준월 **실거래 평균가**(만원), 개수 = 기준월 **실거래 건수** (호가·매물 수가 아닙니다)
- 세대수·구조·방·화는 국토부 실거래 자료에 없어 **직접 입력**합니다. 한 번 입력하면 저장됩니다.
- 목록은 사용 중인 브라우저에 저장됩니다. **[목록 백업]** 으로 파일로 보관하고 다른 PC에서 **[백업 불러오기]** 하세요.

**시세그룹핑** — 생활권(가로)과 가격대(세로)를 만들고 칸에 단지를 적습니다. 트래킹에서 "생활권"을 적어 둔 단지는 [자동 배치]로 한 번에 들어갑니다.

## 나중에 고치고 싶을 때

GitHub에서 파일을 열고 연필(✏) 아이콘으로 수정 → Commit 하면 1~2분 뒤 사이트에 반영됩니다.
Claude에게 **파일 이름과 함께** "이 기능을 추가해 줘"라고 요청하면 해당 파일만 고쳐 받을 수 있습니다.

| 고치고 싶은 것 | 파일 |
|---|---|
| 색상(검정 테마), 글자 크기 | `css/style.css` 맨 위 `:root` |
| 전고점 기준일(2020년), 평형 계산, 연차 계산, 트래킹 엑셀 열 순서 | `js/config.js` |
| 실거래 조회 화면·목록 열·엑셀 | `js/search.js` |
| 시세트래킹 | `js/tracking.js` |
| 시세그룹핑 | `js/grouping.js` |
| 지도 창, 탭, 상태 표시 | `js/app.js` |
| 전고점·등락률 계산식 | `js/data.js` 의 `stats` |

| 수집 규칙(한도, 재시도, 시작 연도) | `scripts/collect.py` 맨 위 "설정" |

## 꼭 알아 둘 점

- **"실시간"의 의미**: 실거래는 계약 후 30일 안에 신고되고, 국토부 공개 자료는 하루 단위로 갱신됩니다. 이 대시보드는 하루 2회 반영합니다.
- **지역코드**: `config/regions.csv` 는 2024년 8월 기준 코드표입니다. 그 이후 바뀐 곳(2026년 인천 제물포구·영종구·검단구 신설, 화성시 4개 구 설치, 광주·전남 통합 등)은 새 코드로 자료가 내려올 수 있습니다. 1년치 이상 받았는데 단지가 0개인 지역은 화면 오른쪽 위에 "⚠ 자료 없는 지역"으로 표시되니, 그때 해당 줄의 코드를 새 코드로 바꾸면 됩니다.
- **해제(취소)된 거래와 월세는 제외**합니다. 직거래는 포함하되 "직거래 제외"를 체크하면 전고점·전저점 계산에서 빠집니다(직거래 구분은 2021년 말 이후 자료부터 제공).
- 평형은 전용면적으로 추정한 값이라 실제 공급평형과 1~2평 다를 수 있습니다. 트래킹 표에서 직접 고칠 수 있습니다.
- 지도는 주소(지번)로 구글 지도를 띄우고, 네이버지도·카카오맵·네이버부동산 버튼으로 바로 넘어갈 수 있습니다.
- 자료 출처: 국토교통부 실거래가 공개시스템 (공공데이터포털)
