# K-apt 세대수 엑셀 올리는 곳

1. 공공데이터포털(data.go.kr)에서 「국토교통부_공동주택 단지 면적 정보」를 검색해 엑셀(xlsx)을 받습니다.
2. 이 kapt 폴더에서 Add file → Upload files 로 그 엑셀을 올리고 Commit 합니다.
3. GitHub 가 자동으로 세대수 자료(data/kapt/*.json)를 만들고 사이트를 다시 올립니다. (Actions 탭 「K-apt 세대수 변환」)
4. 사이트의 시세트래킹 → 🧰 도구 → [세대수 한 번에 채우기] 를 누르면 비어 있는 세대수가 채워집니다.

세대수는 자주 바뀌지 않으니 몇 달에 한 번이면 충분합니다. 이전 엑셀은 자동으로 지워집니다.
